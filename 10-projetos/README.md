# Projetos

Projetos que juntam vários conceitos aprendidos nos módulos anteriores.

| Projeto | Descrição |
|---|---|
| [Calculadora](./01-calculadora) | Calculadora de terminal com as quatro operações básicas. |
| [Jogo de Adivinhação](./02-jogo-adivinhacao) | O computador sorteia um número e o usuário tenta adivinhar. |
| [Sistema de Notas](./03-sistema-notas) | Cadastro de alunos e notas, com cálculo de situação (aprovado/reprovado). |
| [Agenda de Contatos](./04-cadastro-contatos) | Menu para adicionar, listar, buscar, editar e remover contatos. |
| [Gerenciador de Tarefas](./05-gerenciador-tarefas) | Sistema de terminal para adicionar, listar, concluir e remover tarefas, salvando em arquivo. |
