# Lógica de Programação com Python

Repositório dedicado aos meus estudos de lógica de programação e fundamentos de Python.

Este projeto acompanha minha evolução desde os primeiros conceitos de programação até exercícios e pequenos projetos de nível intermediário.

## Objetivos

- Desenvolver raciocínio lógico
- Aprender os fundamentos da programação
- Praticar Python
- Resolver problemas utilizando algoritmos
- Desenvolver autonomia para criar pequenos programas
- Registrar minha evolução durante a graduação em Ciência da Computação
